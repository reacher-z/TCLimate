# TCLimate v0.1.5 — Public Beta

A small update to the unofficial macOS menu bar companion for TCL Home air conditioners.

## Changed

- **Background refresh**: units now refresh every 2 minutes while the panel is closed, so the temperature in the menu bar stays current. The open panel still refreshes every 30 seconds.
- **Offline alerts** now fire from any refresh, so a unit going offline is no longer missed when the panel noticed it first.

## Install

Requires macOS 14 or later and internet access. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available; open it from Finder. Replace any existing copy and keep only one installed copy. Saved sign-ins and Launch at Login carry over from earlier versions.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Other models and regions are unverified. Background refresh and offline alerts only run while TCLimate is open. No local LAN control, direct Google OAuth, or MQTT live subscriptions.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
