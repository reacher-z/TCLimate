# TCLimate v0.1.6 — Public Beta

An update to the unofficial macOS menu bar companion for TCL Home air conditioners.

## New

- **Live updates**: changes made on the unit, its remote, or the TCL Home app now show up as they happen over MQTT. If the live connection drops, TCLimate falls back to regular refreshes.
- **Daily electricity details**: tap a bar in the electricity chart to see that day's kWh and how it compares with the week's average.
- **Right-click menu** on the menu bar icon with Open, Settings, and Quit.

## Changed

- **Smoother panel**: the panel now grows and shrinks with its content when sections open and close, with no jumps or empty space, and clicking the icon again closes it.
- **Offline alerts** check TCL's online status every 60 seconds.
- If macOS hides the menu bar icon, opening TCLimate again from Applications or Spotlight shows the panel.

## Install

Requires macOS 14 or later and internet access. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available; open it from Finder. Replace any existing copy and keep only one installed copy. Saved sign-ins and Launch at Login carry over from earlier versions.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Other models and regions are unverified. Live updates, refreshes, and offline alerts only run while TCLimate is open. No local LAN control or direct Google OAuth.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
